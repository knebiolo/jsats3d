- Coordinate Projection: transform WGS84 latitude/longitude to projected coordinates in EPSG:26910 (UTM Zone 10N NAD83, meters).
- Vertical Datum: hydrophone depths (feet) converted to meters below benchmark/surface (`Z = -depth * 0.3048`).
- Environmental Covariates: derive continuous water temperature (Celsius) and water surface elevation from master covariate tables.
- Chunked Ingestion: large detection CSVs (>10M rows) must be processed using chunked reading (`chunksize=250000` or larger) or single-tag filtering to prevent memory exhaustion.

PROJECT CONTEXT
This project adapts and runs a complete acoustic telemetry data cleaning, clock synchronization, and 3D positioning pipeline for Tacoma Public Utilities (TPU) Cowlitz Falls Dam / Cowlitz River telemetry studies.

Pipeline Steps (order of operations):
1. Ingestion & Database Formatting
   - Ingest raw 2025 deliverables (test, study, beacon, GPS, array metadata, covariates)
   - Map columns into standardized legacy SQLite tables (`tblDetectionRaw`, `tblReceiver`, `tblTag`, `tblInterpolatedTemp`, `tblWSEL`, `tblStudyParameters`)
2. Metronome & Beacon Epoch Enumeration
   - Select master metronome receiver and enumerate transmission epochs (`beacon_epoch`)
   - Filter metronome multipath (`multipath_data_object`, `multipath_2`, `multipath_classifier`)
3. Surface Receiver Clock Synchronization
   - Synchronize stationary surface receiver clocks using time-of-arrival differences (TDoA) and temperature-dependent speed of sound (`clock_fix_object`, `clock_fix`)
4. Beacon Multipath Removal & Deep Receiver Positioning
   - Filter multipath from beacon tags attached to submerged receivers
   - Calculate exact 3D coordinates for deep receivers using Deng et al. (2011) quadratic TDoA algorithm
5. Deep Receiver Clock Synchronization
   - Synchronize submerged receiver clocks using resolved 3D coordinates
6. Study Tag Multipath Filtering
   - Apply primary epoch-rank filter and secondary classifiers to study tag detections across synchronized receivers
7. 3D Positioning & Trajectory Generation
   - Calculate (X, Y, Z, t) positions for study fish using Deng's exact solution across receiver combinations (min 4 receivers)
   - Validate positions against convex hull of receiver array
8. Visualization & Space Use Modeling
   - Generate 3D trajectory plots, diagnostic residual plots, and Kernel Utilization Distributions (KDE / KDA)

Milestones:
- M1: Data Ingestion & Schema Adaptation
  - Build and verify `scripts/adapt_2025_to_legacy.py`
  - Populate legacy SQLite tables from 2025 deliverables
  - Verify legacy module import and environmental interpolation
- M2: Single-Tag & Controlled Test Validation
  - Validate pipeline on controlled tag `FFD3` (15' static hold & drag tracks)
  - Evaluate receiver coordinate accuracy (GPS vs static config)
- M3: Metronome Enumeration & Clock Drift Synchronization
  - Set up study parameters (`tblStudyParameters`)
  - Run beacon epoch enumeration and surface clock synchronization
- M4: Multipath Adaptation for Missing Sensor Signals
  - Implement heuristic / alternate multipath handling for datasets lacking raw `SNR`/`NBW`
- M5: 3D Positioning & Trajectory Validation
  - Execute Deng 2011 positioning on synchronized array
  - Benchmark calculated tracks against array testing drag GPS
- M6: Batch Processing, Reporting & Packaging
  - Full batch processing for study tags
  - Export structured positioning tables, QC plots, and 3D volume models

Each milestone must produce:
- Visible artifacts (SQLite database, CSV, or plots)
- A validation script or test run
- Clear review criteria
