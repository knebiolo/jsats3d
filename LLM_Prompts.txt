########################################################################
1. PROJECT
########################################################################

jsats3d (Kevin Nebiolo, Kleinschmidt) positions acoustic tagged fish in 3D from arrival time
differences using Deng's exact solver. It produced Nebiolo & Meyer (2021), Animal Biotelemetry,
Cowlitz Falls Dam, 2018/2019 Teknologic receivers. This branch keeps one shared code path that
(a) reproduces the 2019 results from the 2019 raw data and (b) runs the 2025 Tacoma Public
Utilities ATS (SR3017) data through the same steps, changing only what 2025 hardware forces
(no SNR/NBW; whole second clock jumps; moving CFD floats).

8.1 Principle

its class BEFORE it is accepted. Record the class, tiers run, numbers and verdict in the journal.

| Class | Required tiers | Pass rule |
| S speed only | T1, T2, T6 | outputs EXACTLY equal (values, dtypes, row order, CSV bytes) |
| C compatibility | T1, T2, T3 | exact, or float difference <= 1e-9 s / 1e-9 m with a written reason |
| B behaviour | owner approval first, then T2 + T4 diff report | change measured and reported, owner signs off |
| N new path | T0, T5 | recovers synthetic truth within the stated tolerance |

T0 Unit tests. Full suite green. Every new function and every fixed bug gets a focused test
