########################################################################
3. HOW SOURCE HEADERS MAP TO DB TABLES
########################################################################

Keys that tie everything together
- Rec_ID     = config "Receiver Name" (e.g. ZOI02). Present in every table.
- Serial     = config "Receiver Serial Number" = raw filename SR<serial> = header
               "Serial Number". The parser maps serial -> Rec_ID from the config.
- Tag_ID     = 4 hex chars. Raw TagCode "G72" + 4 hex + checksum -> chars 4-7
               (G72FFF897 -> FFF8). Config "Beacon Tag Code" -> tblReceiver.Tag_ID
               -> tblTag.Tag_ID (TagType beacon).
- Time       = timeStamp (text) and seconds (float). Both are PDT wall time; seconds
               is that wall time encoded as if UTC epoch. Temperature and WSEL use the
               same local basis, so joins need no conversion.
- Provenance = SourceFile + SourceRow point back to the exact raw line.

tblDetectionRaw  (from raw ATS rows; legacy columns kept, ATS columns added)
  Raw column      -> DB column(s)
  DateTime        -> RawDateTime (receiver wall time as logged)
                     timeStamp, seconds = RawDateTime + TimeShiftHours (study PDT)
                     ReceiverUTCOffsetHours, TimeZoneSource (gps > header > config)
  TagCode         -> Tag_ID
  SigStr          -> SigStr and Amplitude (copied unchanged, not normalised)
  Internal        -> Internal (raw) + InternalGroup1/2/3, InternalFlag, InternalCounter,
                     InternalOffset, InternalStatus, *Value, InternalPositionDifferenceSeconds,
                     OneSecondAdjustmentEvidence, ClockStatusMarker
                     derived: OffsetChanged, CounterRestart, ClockEventReasons
  Temp            -> RawTemperature (99.99 = no sensor)
  Pressure/Tilt   -> Pressure, Tilt (N/A -> NULL)
  VBatt           -> BatteryVoltage
  Bit Period      -> BitPeriod (text, e.g. "240 03/31")
  Threshold       -> Threshold
  GPS Fix row     -> GPSFixTimeStamp (UTC, "+00:00"), GPSFixLatitude, GPSFixLongitude
                     carried onto following detections
  header          -> ReceiverType, FirmwareVersion, FileFormatVersion, SerialNumber
  config          -> Rec_ID
  (none)          -> FreqOff, NBW, SNR, Pascals, Celsius = NULL; Valid = 1; TagTypeSource = raw
  WARNING: DB column Event = 1 when the row carries any clock-event reason.
           It is NOT the deliverable "event" (3 detections in 180 s).

tblReceiver  (config workbook + float GPS)
  Receiver Name -> Rec_ID;  Beacon Tag Code -> Tag_ID
  Lat/Lon (WGS84) -> EPSG:26910 -> minus local origin (E 567994.003, N 5146184.401) -> X, Y
    CFD02-09: X, Y = season median of master_df_gps.csv easting/northing instead.
  Hydrophone Depth (feet) -> Z = -depth x 0.3048 (depth below surface at deployment);
    also HydrophoneDepth_ft. ZReference = depth_below_surface_at_deployment.
  Hydrophone Offset, Total Depth -> HydrophoneOffset_ft, TotalDepth_ft
  Receiver Time Zone Offset -> UTCOffset; Location Description -> MountDescription;
  Deployment Date -> DeploymentDate. X_t/Y_t/Z_t = X/Y/Z (static). Ref_Elev = BM.

tblTag
  Beacon Tag Code + Beacon Tag Period -> Tag_ID, TagType = beacon, pulseRate.
  Study tags (TagType study), provisional pulse rates from measured median spacing:
    FFD3 3.33, FC36 3.038, 0B0A 3.024, 0AC6 3.204, 493F 3.155 s (PENDING PM).
  "Array-wide" 1F14/1F38/1F5A/1F71/1F94/1FCD: no pulseRate in config.

tblInterpolatedTemp  timeStamp, C = mean of all DD_N depths per 5-min step,
  TempSource (DD_N_HOBO to 07-10, DD_N_string after), DepthCount.
tblWSEL              timeStamp, WSEL = NSC.CZD_WTR_EL.F_CV in feet (starts 06-17).
tblStudyParameters   BM_Elev_Units feet, Output_Units meters.
                     UTC_Conv, BM_Elev, masterReceiver, synch_time_* = NULL (BLOCKED).

DBSCAN outputs (output/, gitignored)
  <beacon>_<tag>_anchor_<anchor>_epochs.csv: t, burst, burst_n, t_anchor, anchor_burst_n,
    transNo, Rec_ID, sound_speed, delta_s, label, dbscan_class, resid_s
  Optional --output-db: tblMetronomeFiltered, tblMetronomeSecondFiltered (legacy style).


########################################################################
3A. HOW EACH DATASET IS USED  (headers -> consumer -> purpose)
########################################################################

Format: HEADERS READ | READ BY | USED FOR | LIMITS

Raw ATS receiver files (raw_data\...\SR<serial>*.csv)
  HEADERS  header lines: Serial Number, firmware line, File Format Version, File Start tz.
           columns: Internal, DateTime, TagCode, SigStr, Temp, Pressure, Tilt, VBatt,
           Bit Period, Threshold. GPS Fix/Clock rows: DateTime (UTC) + coords in Internal.
  READ BY  parse_ats_raw_to_legacy.py: discover_target_files(), read_file_metadata(),
           infer_offset_from_gps(), parse_detections().
  USED FOR Every detection in tblDetectionRaw. DateTime = arrival time (the core
           measurement for TDoA). TagCode = which tag. Internal = clock-event evidence
           (jump locations). SigStr = amplitude (candidate multipath feature). GPS Fix
           rows = per-file UTC offset (detection minus GPS time), then carried to rows.
  LIMITS   Only File Format 2.0. D-named daily files skipped (defect). No SNR/NBW/FreqOff.

Config workbook (cowlitz_2025_AT_config.xlsx)
  HEADERS  Receiver Name, Receiver Serial Number, Receiver Time Zone Offset, Beacon Tag
           Code, Beacon Tag Period (sec), Hydrophone Depth (feet), Hydrophone Offset
           (feet), Total Depth (feet), Latitude/Longitude (degrees), Deployment Location
           Description, Deployment Date.
  READ BY  parser (serial -> Rec_ID, config tz offset fallback, beacon list);
           adapt_2025_to_legacy.py load_receiver_table(), load_beacon_registry().
  USED FOR Which files belong to which receiver (serial). Receiver geometry X/Y/Z
           (distance d = |beacon - receiver| drives expected travel time d/c).
           Beacon identity + nominal period (tblTag.pulseRate -> burst split at 0.5 x period).
  LIMITS   Positions: no survey method/accuracy. Periods are nominal (true 7D2D 62.7 s).
           Serial map is static; CFD05/CFD09 swap during tag drag not represented.

Float GPS (master_df_gps.csv)
  HEADERS  dateTime, receiverName, easting, northing (lat, lon unused).
  READ BY  load_receiver_table() (season median -> CFD02-09 X/Y);
           cfd_gps_diagnostics.py (15-min bins, scatter, wander, spikes).
  USED FOR Float receiver positions. Next: time-varying X_t/Y_t from 15-min median and
           test whether float motion explains CFD timing noise.
  LIMITS   Antenna-to-hydrophone offset unknown. Pre-deployment and service-day positions
           must be excluded.

Temperature string + HOBO (Temperature\..., Tag Drag Period\...)
  HEADERS  DateTime, DD_N_0p5, DD_N_1p5, DD_N_9, DD_N_18; HOBO "Date Time, GMT-07:00" + temp.
  READ BY  adapt_2025_to_legacy.py load_temperature_string() -> tblInterpolatedTemp;
           beacon_pairwise_dbscan.py load_temperature() (DB table or --temperature-csv).
  USED FOR Sound speed c = jsats3d.sos(mean DD_N temp) at each ping. c converts distance
           to time: expected TDoA = (d_Bi - d_Ba)/c, and DDoA = c x TDoA.
  LIMITS   1 C error ~ 3 m/s ~ 0.2% range error. Depth-resolved profile = allowed experiment only.

Water level (Master Covariate Table ... NSC.CZD_WTR_EL.F_CV)
  HEADERS  DateTime, NSC.CZD_WTR_EL.F_CV (ft).
  READ BY  adapt_2025_to_legacy.py load_environment() -> tblWSEL;
           legacy clock_fix_object / position (WSELfun interpolator).
  USED FOR Vertical position of receivers that ride the surface: Z(t) = WSE(t) - depth.
           Legacy converts ft -> m at runtime.
  LIMITS   Starts 06-17. No forebay WSE for tag drag (06-05..06-16) or deployment day.

Concatenated deliverables (master_df_*.csv)
  HEADERS  dateTime, tagCode, amp, receiverName, event.
  READ BY  adapt_2025_to_legacy.py normalize_detection() (older demo DBs only).
  USED FOR Gate 0 schema audit and cross-checks of tag counts. Not in v2 DB.
  LIMITS   No Internal/clock evidence, no provenance; amp uncalibrated.

Array testing (5_array_testing\)
  HEADERS  array_testing_drag_GPS.csv: line_name, lat, long, timestamp.
           cowlitz_AT_2025_testing_sheets.xlsx sheets: Upstream StaticHolds,
           Forebay_StaticHolds (Test ID, Date, Start/End Time, Zone, Lat, Long, Comments),
           CFNSC_StaticHolds, Forebay_Approach_Drags, CFNSC_Approach_Drags,
           Forebay_Random_Drags, CFNSC_Drags (Test ID, Date, Start/End Time, Tag Codes, Comments).
  READ BY  Not yet (planned M2/Gate 4).
  USED FOR Ground truth: static-hold RMSE (accuracy) and drag-track overlays.
  LIMITS   Tag drag 06-05..06-10: no forebay WSE, CFD05/CFD09 swap, floats settling.

QC files (6_quality_control\)
  USED FOR Explaining gaps and odd receivers (CFD05 repair, ZOI05 tz, swap note).
  Read manually; not in the pipeline.

PTAGIS (3_PTAGIS_datasets\released_v0.csv, collected_v0.csv)
  USED FOR Fish release/recapture metadata (later). collected Obs Time is PST, not PDT.

4. PROCESSING FLOW AND COMMANDS
########################################################################

conda = "%LOCALAPPDATA%\anaconda3\Scripts\conda.exe" (not on PATH). Prefix: conda run -n jsat_3d python

1. Build DB (done; ~35 min):
   scripts/parse_ats_raw_to_legacy.py <raw_root> --legacy-db --include-config-beacons ...
2. Beacon DBSCAN (read-only on DB; full scan ~3 min without --rowid-range):
   scripts/beacon_pairwise_dbscan.py output/jsats3d_2025_v2.db --beacon-receiver ZOI02
     --anchor ZOI09 --start 2025-06-20 --end 2025-06-22 --output-dir output/dbscan_ddoa_0620
   Writes epochs/segments/summary CSVs and one before/after DDoA plot per receiver
   (DDoA m = c x (t_i - t_anchor) vs seconds, legacy-notebook style).
3. Parameter sweep (no DB access):
   scripts/dbscan_parameter_sweep.py <epochs.csv> --period 60 --output-dir output/dbscan_sweep_0620
4. CFD GPS diagnostics:
   scripts/cfd_gps_diagnostics.py <master_df_gps.csv> --output-dir output/cfd_gps
5. Tests: python -m unittest discover -s tests   (19 pass; pytest not installed)

DBSCAN physics (beacon B heard at receiver i and anchor a):
  delta = (t_i - t_a) - (d_Bi - d_Ba)/c = clock difference + multipath
  Beacon host clock cancels. Clean pings = smooth line; echoes = late isolated points;
  clock jumps = level steps (1 s = ~1,465 m DDoA).
Fixed parameters (scripts/beacon_pairwise_dbscan.py lines 26-36):
  tolerance 0.5 ms (timing budget), window 2.5 pings, min_samples 3,
  anchor-side rule >= 50% of >= 4 receivers, max reflection delay 0.25 s.
Sound speed: legacy jsats3d.sos() (table cites Wikipedia) on DD_N mean temperature.
Rule of thumb: 1 ms timing ~ 1.5 m range; 1 m position ~ 0.68 ms.

5. KEY RESULTS
########################################################################

Clock behaviour (06-17 to 07-01, anchor ZOI09)
- ZOI: clean residual RMS 13-51 us; leave-one-out error median 4.5-8.3 us, p95 15-20 us.
- CFD: RMS 186-229 us; LOO median 84-158 us, p95 407-550 us; 2.4-8.2% over 0.5 ms (WARNING).
- ZOI jumps 0.3-1.1 s, 9-24/day; 78-91% coincide with an Internal flag (ZOI03 38%).
- ZOI02 clock: 164 jumps in 48 h vs 21-30 for cleaner receivers.
- Old "+/-30 s ZOI05 drift" was the UTC logging artifact, not drift.

Beacon coverage (full season, output/beacon_coverage/)
- 8 local beacons heard >= 90% of hours by all 18 working receivers.
- 7D2D (ZOI02) most uniform: median 52 pings/h, minimum 43. Best metronome source.
- "Array-wide" tags 1F14/1F38/1F5A/1F71/1F94/1FCD heard <= 2% of hours: NOT array-wide.
- CFD05 effectively deaf (hydrophone issue per QC tracker).

DBSCAN sweep (output/dbscan_sweep_0620/)
- Current setting sits at the knee: ZOI 4.5% rejected, LOO p95 16 us;
  CFD 13.3% rejected, LOO p95 444 us; 100% of planted echoes (1.5-126 ms) caught.
- Window acts in steps (pings 62.7 s apart): 1.5 = 2.0, 2.5 = 3.0.
- ZOI tolerance > 0.5 ms absorbs echoes/steps (LOO p95 jumps to ~457 us).
- Legacy notebook rule (per-receiver eps = p99 spacing) catches 0-8.5% of echoes
  on 2025 data because 1 s jumps set eps. Unusable until jumps are removed.

CFD float GPS (output/cfd_gps/)
- Within 15 min: ~1 m scatter; fixes > 50 m off <= 0.03%.
- 15-min median wanders 1-10 m (floats move). CFD04 moves most.
- 50-110 m excursions = pre-deployment (before ~06-04/05) and service/download days.
- 15-min mean vs median differ up to 1.4 m (> 0.73 m budget): median recommended.
- Float motion of metres = ms of TDoA; may be part of CFD "clock drift". Check next.
