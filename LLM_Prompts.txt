########################################################################
1. PROJECT IN ONE PARAGRAPH
########################################################################

jsats3d (Kevin Nebiolo, Kleinschmidt) positions acoustic tagged fish in 3D from receiver arrival
time differences (TDoA), using Deng's exact solver. It reproduces Nebiolo & Meyer (2021),
"High precision 3-D coordinates for JSATS tagged fish in an acoustically noisy environment",
Animal Biotelemetry, Cowlitz Falls Dam, 2018/2019 Teknologic receivers. The goal of this branch:
one shared code path that (a) reproduces the 2019 results from the 2019 raw data and (b) runs the
2025 Tacoma Public Utilities Cowlitz Falls ATS data (SR3017 receivers) through the same legacy
steps, changing only what the 2025 hardware forces (no SNR/NBW, clock jumps).
