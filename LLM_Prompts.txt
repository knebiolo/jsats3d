LLM_Prompts.txt
================
Round-trip file between Ethan's local LLM (Copilot) and Claude Code.
Workflow: Claude writes a prompt below. Ethan runs it locally. The local LLM
writes its findings in the RESPONSE block for that prompt. Ethan commits and
pushes to ENM_jsat3d_edits. Claude reads the response and writes the next prompt.

Rules for the local LLM:
- Work only on branch ENM_jsat3d_edits. Never modify main.
- Raw data under K:\Jobs\5662\001\Data\DataTrans\2025_Data is read only.
- Read LONG_TERM_CONTEXT.md and the newest .ai_journal/session file first.
- Do not invent physical values. Mark them BLOCKED with the exact owner question.
- Fill the RESPONSE block in place. Do not delete the prompt.

--- AUDIT ---
For each item report PASS, FAIL, or BLOCKED (needs owner input).
Cite the legacy line number that reads the value.

    (read at jsats3d.py lines 209, 295, 750, 1128).

    (line 213 does .values[0]; empty result raises IndexError).

    (line 1107 ConvexHull fails on NaN).
 4. tblStudyParameters.masterReceiver non-null and matches a Rec_ID
    in tblReceiver (line 762).
 5. tblStudyParameters.BM_Elev non-null (lines 779, 1116).
 6. tblStudyParameters.UTC_Conv non-null.
 7. tblStudyParameters.BM_Elev_Units equals "feet" or "meters", not
    "unknown" (line 783 checks == 'feet' to convert WSEL).
 8. tblInterpolatedTemp min timeStamp <= min tblDetectionRaw.timeStamp
    and max >= max (line 120 uses bounds_error=True; out of range raises).
 9. tblWSEL covers the same detection span
    (interp1d at lines 786 and 1119, no fill_value).
10. tblDetectionRaw contains beacon tag rows, not only FFD3
    (beacon_epoch and clock_fix need beacon detections at host and
    adjacent receivers).
11. Every tblReceiver.Tag_ID appears in tblTag with TagType = "beacon".
12. tblDetectionRaw.SNR is entirely NULL. Report it. Confirm
    multipath_classifier (line 466) is not on the 2025 path and
    multipath_2 or DBSCAN is.
