LLM_Prompts.txt
================
Round-trip file between Ethan's local LLM (Copilot) and Claude Code.
Workflow: Claude writes a prompt below. Ethan runs it locally. The local LLM
writes its findings in the RESPONSE block for that prompt. Ethan commits and
pushes to ENM_jsat3d_edits. Claude reads the response and writes the next prompt.

Rules for the local LLM:
- Work only on branch ENM_jsat3d_edits. Never modify main.
- Raw data under K:\Jobs\5662\001\Data\DataTrans\2025_Data is read only.
- Read LONG_TERM_CONTEXT.md and the newest .ai_journal/session file first.
- Do not invent physical values. Mark them BLOCKED with the exact owner question.
- Fill the RESPONSE block in place. Do not delete the prompt.
