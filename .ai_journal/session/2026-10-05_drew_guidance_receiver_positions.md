KNN used 2 neighbors on standardized amplitude/NBW/SNR with a random 70/30 row split (random_state 111). For groups lacking enough mixed labels, fallback DBSCAN used amplitude/NBW/SNR and removed noise. Thus production KNN was not the only DBSCAN use, but it was the final supervised classifier when run_data selected method KNN. Its printed accuracy/precision/recall score the heuristic labels under a random row split, not surveyed fish truth. The archived 2019 DB's secondary table contains only FF76/FF74/FF78 deep-beacon rows, so no fish classification output exists for parity.
