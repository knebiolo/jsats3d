# Legacy Scripts

The scripts in this directory are unmaintained, exploratory, or project-specific operational scripts.

They are retained for historical reference and project replication purposes, but are **not** part of the supported public `jsats3d` package API.

For supported package usage, import `jsats3d` submodules directly:

```python
import jsats3d as js
```

See [RUNNING.md](../../RUNNING.md) and [README.md](../../README.md) for supported workflows.
